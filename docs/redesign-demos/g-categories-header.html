Categories: where Edit layout and Manage categories go

Today the period sits on one row and the two actions on another, next to a "Visual Distribution" title that just repeats the tab name. The proposals below follow two rules. One primary action per screen. Rare actions go in a menu instead of competing for attention. Whatever ends up holding Edit layout here also goes on Statistics, in the same place and with the same edit bar, so the two pages work the same way.

A. One toolbar row: Manage visible, Edit layout in ⋯ recommended

The title row is gone: the active tab already says "Categories". One row holds the period and filter on the left, then "Manage categories" as a labelled button and a ⋯ menu with "Edit layout". Statistics gets the same row, with only the ⋯.

  • Pro: the shortest header. Statistics and Categories are identical. Edit layout stops competing with content.
  • Con: on a phone, Manage categories is one tap deeper, inside the ⋯ menu.

B. Categories become a strip at the top of the page

Managing categories moves next to the categories themselves. A strip above the charts shows the period's largest categories as chips, with the count and a "Manage" button. The strip is part of the page, so it's visible without looking for it. Edit layout becomes a quiet "Customize this page" link at the end of the widgets, as dashboards usually do.

  • Pro: Manage categories is as visible as it gets, and the strip adds information instead of just a button.
  • Con: one more block on the page. On Statistics the strip makes no sense, so Statistics would only get "Customize this page".

C. Icon buttons in the toolbar, labels from desktop up

Same row as A, but both actions are separate buttons: "Manage categories" with a label, and Edit layout as a grid icon next to the filter. On a phone both shrink to icons with an accessible name and a tooltip on long press.

  • Pro: no menu, one tap for each action.
  • Con: icons with no label (⊞, ◫) are hard to recognise, and the phone row is crowded.

Edit mode, the same on Categories and Statistics (goes with A, B or C)

Today Reset and Done replace the buttons in the header, which scroll away with the page. In this version a floating bar stays at the bottom while you move the widgets, in place of the dock on a phone. Each widget shows a drag handle and a hide button.
