Landing /about: v2 restyle proposals

Three static mocks of the public landing page in the UI v2 "wallet card" language. Each proposal has a 1080px desktop frame and a 375px phone frame, rendered from the same markup. Copy comes from the current landing components, lightly tightened.

  • Dropped: animated background blobs and spheres, coloured glows and halos, animated wordmark. Depth is a neutral shadow or the 1px box ring (light).
  • Brand gradient only on the primary CTA. Wallet colour is a solid fill on the wallet card. Only income is green. Expenses stay in normal text.
  • Numbers use JetBrains Mono with tabular figures, as the v2 token rule in theme-tokens.css sets. Titles use Bricolage Grotesque, text uses Instrument Sans. Sentence case throughout.
  • Use the button in the bottom-right corner to toggle light and dark. Dark is the default, as in the other v2 demos.
A

Product-led

Recommended

Why recommended: the product is on the first screen. A real v2 wallet card and rows explain the app in one glance, and the landing reuses the same components as the dashboard, so it looks like one product.

B

Editorial

Trade-off: a big display headline and one wide app composite. It reads as a magazine, not a SaaS grid, so it sells the story rather than the detail. Strongest on desktop; on a phone the shell collapses to the card and rows.

C

Statement (own direction)

Idea: the landing reads like a monthly statement. The problem is itemised on a receipt, the features are a numbered ledger, and nothing is decorated. It is quieter and more distinctive than A, but it shows less of the product.
