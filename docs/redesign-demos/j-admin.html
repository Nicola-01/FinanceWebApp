Admin dashboard v2: two proposals

Mirrors the current admin tabs (Users with stats, invitations and directory; Backups; System with scheduled jobs and run history) with fake data only. Dark frame only, like the other demos. The admin directory API today returns no email, role or last-login fields, so these mocks assume the backend adds them. Numbers use JetBrains Mono as the brief asks; `frontend/style.md` §8 says v2 avoids mono for amounts, so that is a call to confirm.

A. Segmented tabs, stat tiles, divide-y user list

The current top tab bar becomes a raised segmented control. Stats are a tile row, invites and users are plain divide-y card lists, and every row action sits in one ⋯ menu so the list stays calm.

B. Left sub-nav, sticky users table, list on phone Recommended

Why: the sub-nav has room for future sections (Invites, Backups, System) without crowding the header, the table keeps all the directory columns scannable with a sticky header, and on a phone the same nav becomes a plain list, so one structure covers both sizes.
