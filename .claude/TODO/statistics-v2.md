## Scope
- **v2 only.** The v1 Statistics tab (`StatisticsSummary`, `OverviewTable`, MUI
  `MonthlySnapshotChart`/`CumulativeChart`) stays untouched and its tests stay green.
  The fork lives in `StatisticsTab.tsx` (`// ui-v2-switch`).
- Page order (top → bottom): header with period selector → KPI tiles → Month by month +
  Worth knowing → How the year added up → Fixed vs everyday → Where you're heading →
  Show the numbers (collapsed).
- Data: `useWalletContext().transactions` filtered with `isCategorised` (as today).
  `Transaction`: `amount` (wallet currency, positive), `type: "INCOME" | "EXPENSE"`,
  `transactionDate`, `subscriptionId?` (set = generated by a subscription).
- Charts: shadcn.io kit in `src/components/ui/charts/` (vendored — **never edit it**; import
  via `@/components/ui/charts`; it must stay **lazy-loaded**: the main chunk sits near the
  2 MiB PWA precache cap). Follow the existing pattern in `MonthlySnapshotChart.tsx`
  (`MonthlySnapshotChartV2`), `KitChartShared.tsx`, `kitChartData.ts`, `useChartPalette.ts`,
  `LazyCashFlowSankey.tsx`.
- Colours via `useChartPalette()` / v2 tokens (`--v2-income`, `--v2-expense-mark`,
  `--v2-warn*`, `--v2-danger`, `--wallet`). Light **and** dark must work.

## Known bug to kill
`MonthlySnapshotChartV2` draws bars from the y-domain minimum (−10k, pulled down by the
negative balance line) instead of 0, and squeezes 24+ months with 2 axis labels. The new
"Month by month" replaces it in v2; the old v2 component is deleted at the end (Wave 3).

## Wave 1 — pure logic (parallel: 5 Haiku agents, disjoint files)
Every task: new `.ts` module + Vitest test under `src/__tests__/dashboard/statistics/`,
no React, no kit import. Amounts as numbers; rounding only at display time.

- [x] **T1 `statsPeriod.ts`** — `availableYears(txs)` (desc), `filterByPeriod(txs, period)`
      where `period = { kind: "year", year } | { kind: "all" }`, `previousPeriod(period)`.
      Tests: empty input, year boundaries (31 Dec / 1 Jan, timezone-safe date parsing like
      `chartData.ts` does), all-time.
- [x] **T2 `summaryStats.ts` (extend, keep `summarize` API working for its callers)** —
      `summarizePeriod(txs, period)` → `{ earned, spent, kept, savingsRate | null,
      avgEarnedPerMonth, monthly: { earned[], spent[], kept[], rate[] } (12 slots for a year,
      null for future months), vsPrevious: { spentPct | null, kept | null } }`.
      savingsRate = kept / earned (null when earned = 0). Tests incl. no previous year.
- [x] **T3 `statisticsInsights.ts`** — `buildInsights(txs, period)` → up to 4
      `{ id, tone: "danger" | "income" | "recurring" | "neutral", title, detail }`:
      most expensive month (× median month, + its biggest transaction amount, tag name and
      date), best month (kept + % kept), subscriptions' share of spending (subscriptionId
      set), income steadiness (min–max of monthly income; only if ≥ 3 months with income).
      Skip any insight the data can't support; < 3 months of data → `[]`. English copy as
      in the mock. Tests for each rule + skips.
- [x] **T4 `balanceProjection.ts`** — `projectBalance(monthlyNets: number[], lastBalance,
      horizonMonths, startMonth)` → rows `{ date, balance?, projected?, low?, high? }` for
      the kit (`Band lowerKey="low" upperKey="high"`, `ProjectionLine` from the last real
      point). Pace = **median** of the last 12 monthly nets; σ = MAD × 1.4826 (fallback when
      0); band = ±1.28 × σ × √k. `< 3` months → `null`. Also returns `{ pace, end, endLow,
      endHigh }` for the sub-line. Tests: median ignores an outlier month, band widens with
      k, short history → null.
- [x] **T5 `statsChartRows.ts`** — row builders for the kit:
      `monthByMonthRows(txs, year)` (12 rows: `income`, `expense` **as negative**, `kept`;
      future months empty), `waterfallRows(txs, year)` (opening balance = sum of everything
      before 1 Jan as a total row, 12 signed month nets — stop at the current month — then a
      "Now" total row; use the kit's `totalKey` convention), `fixedVsEverydayRows(txs, year,
      cap)` (`subscriptions`, `everyday`, `everydayCapped`, `overflow` label when capped;
      cap = 1.5 × the 2nd-highest month total). Tests.
