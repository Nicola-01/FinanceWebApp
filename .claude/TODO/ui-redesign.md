# Frontend UI Redesign — TODO

Living plan for the "de-vibecode" frontend redesign. Single source of truth: per-section
restyle checklists + cross-cutting structural work + a living primitives list.

- **Design rules:** [`frontend/style.md`](../../frontend/style.md) (binding). Warm brand
  (violet→magenta), Plus Jakarta Sans + JetBrains Mono, sober squared radii, glass, no
  colored glow, no animated wordmark, per-wallet `wallet.color` accent, primitives in
  `src/components/ui/`.
- **Method:** one screen/increment at a time; get sign-off on taste before sweeping;
  structural fixes can proceed. Run `npm run lint` + `npm run build` after each increment.
- **Auth screens are always dark** (shared `AuthLayout` shell); the dashboard is themed
  (warm off-white light / warm violet-night dark).

**Legend:** `[x]` done · `[~]` partial/in progress · `[ ]` todo · **DECISION** = needs the
user's call.

contract — imperative `openModal()` handle + `onSuccess(walletId)` prop — wired to the **New
Wallet** button in `dashboard/wallet/WalletsBar.tsx`. `CreateWalletModal.tsx` was **deleted**
(the entry in §10's "migrated" list is now historical). All copy English; tokens `app-*`.

**Shell & flow (`CreateWalletWizard.tsx`):**
- [x] Hosted in `WizardShell` (full-screen portal, Esc, body-scroll lock) + generic `Wizard`
  stepper (`components/ui/`); each step body is a self-contained `wizardSteps/*` component fully
  controlled via `value`/`onChange` on a single `WalletDraft`.
- [x] **5 steps** (order): **Basics** (mandatory — name 3–25) → **Tags** (opt) → **Transactions**
  (opt) → **Subscriptions** (opt) → **Invite** (opt). Optional steps show a
  `nextLabelIncomplete` ("Continue without …", never "Skip"); accent = `basics.color`.
- [x] **Completion phase** (`walletCreation.ts`, decoupled/unit-testable): creates the wallet
  first (blocking — `WalletCreateError` on failure), then fires the staged bulk imports in
  parallel (`/tags|/subscription|/transactions/{id}/bulk`, all-or-nothing per resource) + loops
  invites (`/invitations/{id}`). Terminal screen: processing → per-resource recap
  (created/updated/sent counts, partial-failure = wallet kept) → **Go to wallet**.
- [x] Discard-confirm (`ConfirmModal`) on X/Esc while the draft is dirty; reopen remounts fresh (`runKey`).

**Steps:**
- [x] **Basics** (`BasicsStep`) — name, description, icon (`IconPickerButton`), colour, currency.
- [x] **Tags** (`TagsStep` + `tagModes/`) — `Selector` across **4 modes**: **Recommended**
  (`RecommendedTagMode`, curated `recommendedTags.ts` groups), **From wallet** (`WalletTagMode`,
  sourced via `fetchTagSources()` in `sourceWallets.ts`), **CSV** (`CsvTagMode` → `CsvUploadField`,
  uploaded tags shown as preselected cards), **Create** (`TagCreateMode`). All feed one staged
  `StagedTagTree` with provenance badges, strike-out/restore of sub-tags, category toggling.
- [x] **Transactions** (`TransactionsStep`) — CSV-only via `CsvUploadField`; staged preview (first 5 + "+N more"), Clear.
- [x] **Subscriptions** (`SubscriptionsStep` + `subscriptionModes/`) — `Selector` across **3 modes**:
  **Recommended** (`RecommendedSubscriptionPicker`, editable amounts, `recommendedSubscriptions.ts`),
  **CSV** (`CsvUploadField`), **Create** (`SubscriptionCreateMode`, uses `SchedulingRules` +
  `TagTreePicker`). Staged in `StagedSubscriptionList`. **Blocking:** a staged sub whose tag isn't
  in the draft is flagged amber and blocks Continue (`hasUnresolvedSubscriptionTags`,
  `subscriptionTags.ts`) until reassigned or the tag is created (recreates the recommended
  hierarchy when the leaf is known).
- [x] **Invite** (`InvitesStep`) — email/username + `Selector` Viewer/Editor; staged list with per-row role switch + remove.
